# Code of Conduct

## Our commitment

We are committed to making participation in this project a respectful and harassment-free experience for everyone, regardless of experience level, background, or identity.

## Standards

Behavior that contributes to a positive environment:

- Being respectful and constructive in code review and discussion
- Accepting feedback gracefully
- Focusing on what is best for the project

Behavior that is not acceptable:

- Harassment or discriminatory language of any kind
- Personal attacks or insults
- Deliberate intimidation or trolling
- Publishing others' private information without consent

## Scope

This code of conduct applies in all project spaces -- GitHub issues, pull requests, discussions, and any other forum where community members interact on behalf of this project.

## Enforcement

Report violations to [efe@efebehar.dev](mailto:efe@efebehar.dev). All reports will be reviewed and investigated promptly and kept confidential.

Maintainers reserve the right to remove, edit, or reject contributions that do not align with this code of conduct, and to ban contributors for behaviors deemed inappropriate.
